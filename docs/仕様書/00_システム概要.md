# Torifune OSS システム概要

## 1. 目的

Torifuneは、WebサイトやSNSなどのマーケティング活動に必要な機能を一元的に管理・運用するためのオープンソースソフトウェアである。

Torifune OSSは、特定のサービス事業者や認証基盤に依存せず、単体のアプリケーションとして利用できることを基本方針とする。

また、プラグイン機構を標準機能として提供し、第三者がTorifuneの機能を拡張できる構造を採用する。

## 2. 基本方針

Torifune OSSは、以下を基本方針とする。

### 2.1 独立したアプリケーション

Torifune OSSは、外部のユーザー管理サービスやSaaS基盤を必要とせず、単体のアプリケーションとして動作できるものとする。

標準構成では、1つのTorifuneインスタンスが1つのデータベースを使用する。

### 2.2 オープンな拡張性

Torifune本体にすべての機能を直接実装するのではなく、プラグイン機構を利用して機能を追加できる構造とする。

プラグインによって、例えば以下の機能を追加・拡張できるものとする。

* 画面・メニューの追加
* Torifuneが保持するデータへのアクセス
* 外部サービスとの連携
* イベント処理
* 認証方式の変更
* データベース接続方式の変更
* その他、Torifuneが提供するPlugin APIの範囲内での機能拡張

### 2.3 コア機能と拡張機能の分離

Torifune本体は、マーケティング管理に必要な基本機能を提供する。

一方、特定のサービスや利用環境に依存する機能は、可能な限りプラグインとして実装する。

これにより、Torifune本体の汎用性を維持しながら、利用者や開発者が用途に応じて機能を拡張できるようにする。

## 3. システムの基本構成

Torifune OSSは、基本的に以下の構成で動作する。

```text
┌──────────────────────────────┐
│        Torifune          │
│                              │
│  Web UI / API                │
│  Core Functions              │
│  Plugin System               │
│  Authentication              │
│  Data Access                 │
└──────────────┬───────────────┘
               │
               │ Database Connection
               ▼
┌──────────────────────────────┐
│         PostgreSQL           │
│                              │
│   Torifune Database      │
└──────────────────────────────┘
```

TorifuneはアプリケーションとしてWeb UIおよびAPIを提供し、データの永続化にはPostgreSQLを使用する。

## 4. データベース

Torifune OSSでは、PostgreSQLを標準のデータベースとして使用する。

標準構成では、Torifuneインスタンスとデータベースは1対1の関係とする。

```text
Torifune Instance
        │
        └── PostgreSQL Database
```

データベースの初期化、テーブル作成、マイグレーション等については、データベース設計で定義する。

また、データベース接続処理はプラグインによって拡張可能な設計とする。

## 5. 認証

Torifune OSSは、標準的な認証機能を提供する。

ただし、認証処理をTorifune本体の各機能から直接利用するのではなく、Authentication Providerとして抽象化する。

これにより、プラグインによって認証方式を差し替えられるようにする。

例えば、以下のような認証方式を実装可能とする。

* Torifune標準認証
* OpenID Connect
* OAuth 2.0 / OpenID Connectを利用した外部認証
* その他のAuthentication Provider

認証機構の詳細については「04_認証設計.md」で定義する。

## 6. プラグインシステム

Torifune OSSでは、プラグインを正式な拡張機構として提供する。

プラグインは、Torifuneが定義したPlugin APIを利用して本体の機能を拡張する。

主な拡張ポイントとして、以下を想定する。

```text
Plugin
├── UI Extension
├── Data API
├── Event API
├── Authentication Provider
├── Database Provider
└── External Service Integration
```

プラグインの詳細な仕様については「03_プラグイン設計.md」で定義する。

## 7. 画面

Torifuneは、Webブラウザから利用可能な管理画面を提供する。

また、プラグインによってTorifuneの画面に以下のような拡張を追加できるものとする。

* メニュー
* ページ
* ダッシュボードウィジェット
* 設定画面
* データ表示
* 操作用UI

プラグインがTorifuneの内部実装に直接依存するのではなく、定義されたUI拡張APIを利用することを基本とする。

## 8. API

Torifuneは、内部機能およびプラグインから利用可能なAPIを提供する。

APIは、主に以下の用途を想定する。

* Torifuneのデータ取得
* データ登録・更新
* 認証情報へのアクセス
* イベントの購読
* UI拡張
* プラグイン間連携

「認証情報へのアクセス」は、**いま操作している利用者が誰かを知ること**を指す
（`PluginContext.currentUser`）。プラグインへ渡すのは表示と判断に要る範囲に限り、
パスワードのハッシュ・メールアドレス・外部サービスのトークンは渡さない。
認証方式そのものの差し替えは Authentication Provider の役目で、別物とする（§5）。

APIの詳細については「05_API設計.md」で定義する。

## 9. OSSとしての位置付け

Torifune OSSは、特定のSaaSサービスを利用するための専用アプリケーションではなく、独立したオープンソースソフトウェアとして提供する。

そのため、以下の要素をTorifune OSSの必須条件とはしない。

* 特定のクラウドサービス
* 特定のSaaS運営基盤
* 特定のユーザー管理サービス
* 特定のマルチテナント管理方式
* 特定の課金システム
* 特定のデプロイ環境

これらが必要な場合は、Torifuneのプラグイン機構や外部システムとの連携によって実現する。

## 10. SaaS版との関係

Torifune OSSとは別に、TorifuneをSaaSとして提供するための非公開システムを構築する。

SaaS版では、Torifune OSSをベースとして、別途ユーザー管理、認証基盤、テナント管理、データベース管理、コンテナ管理等を提供する。

```text
┌──────────────────────────────────┐
│       Torifune SaaS          │
│                                  │
│ User Management                  │
│ Authentication / Tenant Control  │
│ Container Management             │
│ Database Management              │
│                                  │
│       Plugin                     │
│          │                       │
│          ▼                       │
│   ┌──────────────────────┐       │
│   │   Torifune OSS   │       │
│   └──────────┬───────────┘       │
└──────────────┼───────────────────┘
               │
               ▼
          PostgreSQL
```

SaaS版固有の機能はTorifune OSS本体に直接組み込まず、可能な限りプラグインまたは外部システムとして実装する。

これにより、Torifune OSSの独立性を維持しながら、SaaSとして必要な機能を追加できる構造とする。

## 11. 設計上の責務境界

Torifune OSSとSaaS基盤の責務は明確に分離する。

| 項目                | Torifune OSS | SaaS基盤 |
| ----------------- | ---------------- | ------ |
| マーケティング機能         | ○                |        |
| Web UI            | ○                |        |
| API               | ○                |        |
| プラグイン機構           | ○                |        |
| 標準認証              | ○                |        |
| 認証Provider        | ○                | ○      |
| Database Provider | ○                | ○      |
| ユーザー登録・管理         |                  | ○      |
| テナント管理            |                  | ○      |
| ユーザーごとのDB管理       |                  | ○      |
| コンテナ管理            |                  | ○      |
| 課金・契約管理           |                  | ○      |
| SaaS運用管理          |                  | ○      |

この責務境界を維持することで、Torifune OSSは独立したソフトウェアとして利用可能でありながら、プラグインによってSaaS環境へ柔軟に統合できる構造を実現する。
