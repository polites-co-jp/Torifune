### 指摘

#### S-1（記録）Plugin ごとの総容量に上限が無い

1値は 256KB に制限しているが、**キーの数に上限が無い**。
Plugin ひとつでデータベースを埋められる。

`012-plugin-manager` で、Plugin ごとの使用量を表示し、
上限を設けることを検討する。

#### S-2（記録）Plugin は信頼されたコードである

`03_プラグイン設計.md` §20 のとおり、Plugin はサンドボックスで隔離されない。
ここで作った境界は「うっかり越えない」ための構造であって、
**悪意ある Plugin を止めるものではない**。

`SECURITY.md` にその旨を明記済み。

## 4. 仕様書との相違（1件）

`03_プラグイン設計.md` §16 は Plugin ID の例として `example.plugin` を挙げているが、
**実装ではドットを許さない**（英小文字・数字・ハイフンのみ）。

理由：Plugin ID は URL（`/plugins/<id>/`）とデータの名前空間になるため、
ドットは扱いにくい。仕様書は「例」として挙げているだけで形式を規定していないため、
仕様の改訂は不要と判断した。
