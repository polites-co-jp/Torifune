# SNS管理 設計

## 1. 目的

SNSアカウントと投稿を Torifune で管理できるようにする。

**外部SNSとの実連携は Plugin の責務**（`01_アーキテクチャ設計.md` §12、
`03_プラグイン設計.md` §9）。Core が持つのは「データの箱と状態管理」まで。

このスプリントには、Secret を扱う最初の実例という役割もある。
`006-secret-storage` を実際に使い、平文が外へ出ない経路を確立する。

## 3. スコープ

### やること

* `social_accounts`（provider / 表示名 / 暗号化した資格情報 / 状態）
* `social_posts`（投稿本文 / 予約時刻 / 状態 / 結果の記録）
* CRUD の UseCase・API・画面
* Secret の保存と「設定済み」表示
* Event の発火

### やらないこと

* **外部SNSへの実投稿**（Plugin の責務）
* OAuth フロー（Plugin の責務）
* 予約投稿の実行スケジューラ（`012-background-worker` 相当。次計画）
* SNSからの取得（インプレッション等。`018-analytics`）

**Core は「投稿を登録できるが、実際には配信されない」状態で正しい。**
画面にその旨を明示する。誤解を招きやすいため。

## 5. データモデル

### `social_accounts`（`migrations/005_social.sql`）

| カラム | 型 | 制約 |
| --- | --- | --- |
| `id` | `uuid` | PK |
| `provider` | `text` | NOT NULL。`x` / `facebook` / `instagram` / `other` |
| `display_name` | `text` | NOT NULL、空文字不可 |
| `handle` | `text` | NOT NULL DEFAULT `''`（`@name` 等） |
| `credential` | `text` | NULL 可。**暗号化した文字列**（`006-secret-storage` の形式） |
| `status` | `text` | NOT NULL、CHECK in (`connected`, `disconnected`, `error`) |
| `created_at` / `updated_at` | `timestamptz` | NOT NULL DEFAULT `now()` |

**`provider` を DB の CHECK 制約で固定しない。**
Plugin が新しいSNSを足せる必要がある（`03_プラグイン設計.md` §9）。
Core が知っている値は列挙するが、未知の値も受け入れる。

> ただし**入力の形式は制限する**（英小文字・数字・アンダースコア）。
> 任意の文字列を通すと、画面や URL で扱いにくくなる。

### `social_posts`

| カラム | 型 | 制約 |
| --- | --- | --- |
| `id` | `uuid` | PK |
| `social_account_id` | `uuid` | NOT NULL, FK → `social_accounts(id)` ON DELETE CASCADE |
| `body` | `text` | NOT NULL、空文字不可、1〜10000文字 |
| `scheduled_at` | `timestamptz` | NULL 可 |
| `status` | `text` | NOT NULL、CHECK in (`draft`, `scheduled`, `published`, `failed`) |
| `published_at` | `timestamptz` | NULL 可 |
| `failure_reason` | `text` | NULL 可 |
| `created_at` / `updated_at` | `timestamptz` | NOT NULL DEFAULT `now()` |

**アカウントを削除したら投稿も消す**（`ON DELETE CASCADE`）。
アカウントから切り離された投稿は、どこへ出すものか分からず意味を持たない。

### 状態遷移

```text
draft ──→ scheduled ──→ published
  │           │
  └───────────┴──→ failed
```

`published` と `failed` からは戻せない。**起きた事実は書き換えない。**

### Index

| 対象 | 目的 |
| --- | --- |
| `social_accounts(provider)` | 絞り込み |
| `social_posts(social_account_id, created_at DESC)` | アカウント単位の一覧 |
| `social_posts(status, scheduled_at)` | 予約投稿の取り出し（将来のワーカー用） |

### アカウントの応答

```jsonc
{
  "data": {
    "id": "…", "provider": "x", "displayName": "とりふね公式", "handle": "@torifune",
    "status": "connected",
    "credentialConfigured": true,   // ← 平文は返さない
    "createdAt": "…", "updatedAt": "…"
  }
}
```

**`credential` を返さない。** 設定済みかどうかだけを返す（`05_API設計.md` §18）。

## 7. 画面

### `/social` 一覧（アカウント）

型A。`SecretField` で資格情報を扱う。設定済みなら `••••••` とだけ表示する。

**画面上部に「Core は投稿を登録するところまで。実際の配信は連携Pluginが行う」旨を出す。**
出さないと、投稿したつもりで配信されていない、という誤解が起きる。

### `/social/posts` 一覧（投稿）

型A。アカウントで絞り込める。

## 9. Plugin API への影響

S10 で次を公開する。

* Data API の `socialAccounts` / `socialPosts`
* Event：`social.account.connected` / `social.post.created` / `social.post.published` /
  `social.post.failed`
* **資格情報の読み出し口**：外部SNSを叩くのは Plugin なので、
  復号した値を Plugin へ渡す経路が要る。**読み出したことを監査できる形にする**

## 10. 受け入れ条件

### アカウント

1. アカウントを作成できる
2. `provider` の形式が不正なら 422（大文字・記号・空文字）
3. Core が知らない `provider` でも作成できる（Plugin の拡張余地）
4. 表示名が空なら 422
5. **資格情報が DB 上で平文になっていない**
6. **API 応答に資格情報が含まれない**
7. API 応答に `credentialConfigured` が入る
8. 資格情報を設定していなければ `credentialConfigured` が false
9. 資格情報を更新できる
10. 資格情報を指定しない更新で、既存の資格情報が消えない
11. 一覧を provider で絞り込める
12. 権限あり200 / 権限なし403 / 未認証401

### 投稿

13. 投稿を作成できる
14. 本文が空なら 422
15. 本文が 10000 文字を超えたら 422
16. 存在しないアカウントIDで作成すると 422 または 404
17. アカウントで絞り込める
18. 状態で絞り込める
19. `published` から `draft` へ戻せない
20. `failed` から `draft` へ戻せない
21. `draft` → `scheduled` → `published` へ進める
22. アカウントを削除すると、その投稿も消える
23. 権限あり200 / 権限なし403 / 未認証401

### Secret の取り扱い

24. **ログに資格情報の平文が出ない**
25. **エラー応答に資格情報の平文が出ない**
26. 資格情報を復号して取り出せる（内部利用）
27. 鍵が違えば復号に失敗する

### Event

28. アカウント作成で `social.account.connected` が発火する
29. 投稿作成で `social.post.created` が発火する
30. **イベントのペイロードに資格情報が含まれない**

### 画面

31. アカウント一覧が表示される
32. 資格情報がマスク表示される
33. **「実際の配信は連携Pluginが行う」旨が表示される**
34. 投稿一覧が表示される
