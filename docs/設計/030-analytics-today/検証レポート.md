### 2.2 E2E は Rate Limit に当たって不安定

`analytics.spec.ts`（`当日` 36 件を含む）は**繰り返し全件通過**する。一方、
**毎回別のファイル**が HTTP 429 で落ちる（`sites` / `social` / `api-token` / `jobs` / `password-reset`）。

* `DEFAULT_RATE_LIMIT = { windowMs: 60_000, max: 300 }`、キーは `operationId:IP`
* 実行が速いほど失敗が増える（1.5 分で 24 件 / 1.9 分で 8 件）。Rate Limit そのものの挙動
* `playwright.config.ts` は `retries: CI ? 2 : 0`。**CI では 60 秒窓を跨いでリトライされ吸収されるが、
  ローカルはリトライ 0 なのでそのまま失敗として出る**

030 が追加した E2E の要求密度が上限を押し上げたことが原因。**本体の Rate Limit は緩めない。**
対処はユーザー裁定を仰ぐ（§4）。
