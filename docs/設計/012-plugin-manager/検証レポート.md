### 気をつけた点

**コンテナの話を Torifune 本体へ持ち込まない。**
再ビルドの仕組みは「sentinel を書いて終了コード 75 で落ちる」までを本体の責務とし、
それをどう受けるかは `docker/entrypoint.sh` に閉じている。
Kubernetes でも systemd でも、同じ約束で受けられる。

`TORIFUNE_SELF_RESTART` が無ければ落ちない。
監視ループを持たない実行環境を前提から外していない。

### 指摘

#### S-1（対応済み）名前の検証が2箇所に分かれていた

当初、yauzl の既定の検証がパスを弾いていた。動作としては安全だが、
**こちらの `isUnsafePath` が一度も試されないまま残る。**
yauzl の実装や既定が変われば、気づかないうちに穴が開く。

`decodeStrings: false` で yauzl の検証を外し、検証を1箇所へ集めた。
展開時の `startsWith` は意図的に残した二重の確認である。

#### S-2（記録）Plugin の導入はコード導入である

`plugin.manage` はインスタンス管理者の権限であり、
サイト運用者に配ってよいものではない。設計 §11 に明記した。

zip の展開そのものは攻撃面として扱い、Plugin の外へ書き込ませない。
一方、**展開されたコードの中身は信頼する前提**に立つ（`CLAUDE.md`）。
これは仕様書 03 §29 と整合する。

#### S-3（記録）アップロードの上限がプロセスの実メモリを決める

`inspectPackage` は zip 全体をメモリへ載せる。
上限（既定 32 MiB）× 同時アップロード数だけ確保されうる。

`plugin.manage` を持つ管理者しか叩けないため実害は小さいが、
**上限を上げる運用では同時実行を絞る必要がある。**
`03_リスクと未決事項.md` へ回す。

#### S-4（記録）ビルド中は応答が返らない

再ビルド中、そのインスタンスは落ちている。
利用者から見ると「数分の停止」である。設計 §10.2 で押す前に伝えている。

**複数インスタンスで動かす構成は Torifune 本体の前提に無い**（1インスタンス = 1DB）。
そのような構成が要るなら、それは TorifuneHub 側の関心である。

## 4. 設計書との相違（3件）

### 4.1 #30「ビルドに失敗しても、再起動後に直前の正常な状態で立ち上がる」

**ロールバックそのものは `docker/entrypoint.sh` の責務**で、S0 のスパイクで
実機確認済み（`03_リスクと未決事項.md` R-01）。

本スプリントで確認したのは、**戻ったあとにアプリが何をするか**である
（操作を `failed` にする・隔離する・行を消す）。これは 10 件で検証した。

「ビルドを実際に失敗させて通しで確認する」は、コンテナを立てる必要があり
自動テストに載せていない。**S13 で例示 Plugin を使って手動確認する。**

### 4.2 API のパスを設計書から変えた

設計 §9 は `POST /api/v1/plugins/upload` としていたが、
検証と導入を分ける必要があるため2つに割った。

| 設計書 | 実装 |
| --- | --- |
| `POST /plugins/upload` | `POST /plugins/package/inspect`（検証のみ） |
| （なし） | `POST /plugins/package/install`（展開して導入） |

### 4.3 `defineRoute` に `bodyKind` を足した

ファイルを受け取るために要る。既定は `json` のままで、既存のルートは変わらない。
`raw` のときはハンドラが自分でボディを読み、CSRF トークンは
`x-csrf-token` ヘッダで受ける（`verifyCsrf` は元からヘッダを見ている）。

大きなボディを JSON として読もうとすると、その分だけ無駄に確保する。

## 8. 総合判定

**S12 の受け入れ条件を満たしている。**

管理画面から Plugin を導入・有効化・無効化・削除できる。
要求 Permission は導入前に見せ、同意しなければ入らない。
再ビルドを伴うことは押す前に伝え、失敗しても直前の状態へ戻る。

セキュリティ観点で最も重いのは zip の展開であり、
**拒否したい形をすべて自前で作って試した**（`test-support/zip.ts`）。
拒否したときに1バイトも書かれていないことも確認した。
