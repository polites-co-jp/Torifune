### 指摘

#### S-1（記録）`created_by` を API で返していない

内部の関係を外へ出さない判断だが、「誰が作ったか」を画面に出したくなったら
Permission を検討したうえで足す（例：`user.manage` を持つ場合だけ返す）。

#### S-2（記録）サイト単位の権限は無い

`site.read` を持つ利用者は**すべてのサイト**を見られる。
サイトごとにアクセスを分けたい要件が出たら、別途設計が要る。
`設計.md` §3 のとおり今回のスコープ外。

## 4. E2E のテスト設計の見直し（このスプリントで行った）

サイトの E2E を足したところ、テストごとにログインしていたため
**ログインの Rate Limit に当たって4件が落ちた**。

製品の不具合ではなくテストの設計の問題として、`globalSetup` で1回ログインし
`storageState` を共有する形へ変えた。

* ログアウトを試すテストは自前でログインする。共有セッションでログアウトすると
  サーバー側でそれが失効し、他のテストファイルまで巻き添えになる
* 副次的に E2E 全体が 1.4 分 → 11 秒へ短縮された
