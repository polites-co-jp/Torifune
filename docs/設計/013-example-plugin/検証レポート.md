### 指摘

#### S-1（対応済み）画面の Data API が「起動したときのユーザー」に縛られていた

`activate()` で受け取る `context.data` は、そのとき Plugin を起動した
ユーザーの認可文脈を握っている。`ensurePluginsStarted` は1度しか走らないため、
**それは「起動後に最初にアクセスした人」である。**

その Data API を Widget やページの描画で使うと、
**見ている人と違う権限でデータを読む**ことになる。
権限の弱いユーザーの画面に、強い権限でしか見えないものが出うる。

描画する部品には**その要求の Data API を props で渡す**ようにした。
そのために、レジストリの収集結果へ「どの Plugin のものか」を添えている。

手引きにも「`activate` の `context.data` を画面で使わない」と明記した。

#### S-2（対応済み）プロセス内でレジストリが分裂していた

E2E で発覚した。**API から無効化したのに、画面から Plugin が消えなかった。**

Next.js は Route Handler と Server Component を別のバンドルへ分けることがあり、
同じモジュールの実体が複数になる。モジュール変数に持っていた

* Plugin のレジストリ（読み込み済み・登録内容）
* 起動状態（`bootPromise`）
* Permission のレジストリ
* イベントのハンドラ

が経路ごとに別物になっていた。

`infrastructure/process-state.ts` を作り、`globalThis` 上の1つを共有するようにした。
**これは Plugin に限らない問題**で、イベントは
「Plugin が購読したのに発火が届かない」という壊れ方をしていた。

#### S-3（記録）Database Provider の差し替えは元へ戻らない

無効化しても `setDatabaseProvider` を戻していない。
戻すには再起動が要る。

動いている最中に接続方式を差し替えると、走っている処理が道連れになるため。
レジストリには「差し替えた Provider の ID」を記録している。

#### S-4（記録）Plugin は信頼されたコードである

サンプルは無害だが、Plugin は本体と同じプロセス・同じ権限で動く。
特に Database Provider は高い権限を持つ。
手引きの最後にこれを明記した。

## 4. 設計書との相違（2件）

### 4.1 サンプルは既定で Database Provider を差し替えない

設計 §3 は「ダミー Database Provider」を挙げているが、
**有効化しただけで差し替えると本体が何も読めなくなる。**

`EXAMPLE_PLUGIN_REPLACE_DATABASE=1` のときだけ差し替える形にした。
差し替えが成立すること自体は `database-adapter.test.ts` で確かめている
（SQL が届く・パラメータで渡る・BEGIN/COMMIT/ROLLBACK・入れ子の参加・
healthCheck が例外を投げない・切断が伝わる）。

### 4.2 Authentication Provider の差し替え口は作っていない

`PLUGIN_EXTENSION_KINDS` は `authentication` を含み、Manifest で宣言できるが、
**`PluginContext` に登録の口が無い。宣言しても使えない。**

差し替えを実際に使うサンプルが無いまま口だけ作ると、
使われない形を先に固めることになる。`03_リスクと未決事項.md` へ回した。

`database` と同じ形（`context.authentication.registerProvider` と
宣言の検査）で足せる。

## 8. 総合判定

**S13 の受け入れ条件を満たしている。マイルストーンA の目的を果たした。**

サンプル Plugin は `@torifune/plugin-api` だけを使い、
本体のコードに Plugin 固有の分岐を1つも持たずに、
メニュー・ページ・Widget・Action・拡張点・イベント・設定・Data API・
Database Provider のすべてを動かしている。

**サンプルを書いたことで、書かなければ見つからなかった欠陥が2つ出た**
（S-1 の権限の取り違え、S-2 のレジストリの分裂）。
どちらも本番で起きれば分かりにくい壊れ方をするもので、
契約とランタイムを作っただけでは見つからなかった。
