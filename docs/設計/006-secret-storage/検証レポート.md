### 指摘

#### S-1（記録）`expose()` の乱用を機械的に防いでいない

`expose()` を呼べば平文が取れる。呼び出し箇所が増えると、
どこかで API レスポンスや画面へ流れる危険がある。

現状は「grep できる」「レビューできる」までで止めている。
`009-social` と `011-plugin-runtime` で実際の呼び出し箇所が確定したら、
ESLint 規則で許可リスト方式にすることを検討する。

#### S-2（記録）鍵ローテーションは器だけ

`wrong_key` を返す仕組みはあるが、**旧鍵で再試行する経路は実装していない**。
実際にローテーションするときは、複数の鍵を保持して順に試す実装が要る。
運用手順とあわせて別途設計する。
