### 確定事項（蒸し返さない）

* 適用範囲は**インスタンスに 1 つ**。サイトごとは作らない（要件 §3.1）
* 指定形式は**完全一致＋CIDR**、IPv4 / IPv6 両方。判定は Domain に自前実装（要件 §3.2）
* 除外は**記録の手前**でのみ行う。遡及削除も再集計もしない（設計 §2 / §11）
* 参照は**非同期のみ**。キャッシュが古ければ待つ（設計 §6.2）
* 読み直しの失敗は **fail-open**（記録する側へ倒す。設計 §6.3）
* リストは `PublicSystemSettings` に**載せない**（設計 §5）

## 3. 受け入れ条件

### 3.1 Domain：アドレスの解釈（設計 §4.1）

* **#1** `parseIpAddress('203.0.113.10')` は family `v4`・4 バイト `[203,0,113,10]`
* **#2** `parseIpAddress('2001:db8::1')` は family `v6`・16 バイト
* **#3** `parseIpAddress('::ffff:203.0.113.10')` は **family `v4`・4 バイト**（IPv4 射影を畳む）
* **#4** `parseIpAddress('010.0.0.1')` は `null`（先頭ゼロを認めない）
* **#5** `parseIpAddress('256.0.0.1')` / `'1.2.3'` / `'1.2.3.4.5'` / `''` / `'::ffff:'` は `null`
* **#6** `parseIpAddress('2001:db8::1::2')` は `null`（`::` は 1 回まで）
* **#7** `parseIpAddress('::')` は family `v6`・全 0 の 16 バイト
* **#8** どんな入力でも**例外を投げない**

### 3.2 Domain：送信元の正規化（設計 §4.2）

* **#9**〜**#15** 設計 §4.2 の表の 7 行がそのまま成り立つ
* **#16** `normalizeClientIp('2001:db8::1')` は `'2001:db8::1'`（コロンが複数：ポートを落とさない）
* **#17** `normalizeClientIp(null)` は `null`

### 3.3 Domain：ルールの解釈（設計 §4.3）

* **#18** `parseIpExclusionRule('203.0.113.10')` は `prefixLength = 32`・`text = '203.0.113.10'`
* **#19** `parseIpExclusionRule('203.0.113.10/32')` の `text` も `'203.0.113.10'`（`/32` を落とす）
* **#20** `parseIpExclusionRule('203.0.113.10/24')` の `text` は `'203.0.113.0/24'`（ホスト部をマスク）
* **#21** `parseIpExclusionRule('2001:db8:0:0:0:0:0:1/128')` の `text` は `'2001:db8::1'`（小文字・`::` 圧縮・`/128` を落とす）
* **#22** `parseIpExclusionRule('2001:0db8:abcd:1234::/64')` の `text` は `'2001:db8:abcd:1234::/64'`
* **#23** `prefixLength` の境界：v4 は `0`〜`32` が通り `33` は `null`、v6 は `0`〜`128` が通り `129` は `null`
* **#24** `'203.0.113.0/024'` / `'203.0.113.0/'` / `'203.0.113.0/x'` / `'203.0.113.0/1/2'` は `null`

### 3.4 Domain：一致（設計 §4.4）

* **#25** `203.0.113.10` は `203.0.113.10` に一致し、`203.0.113.11` には一致しない
* **#26** `203.0.113.77` は `203.0.113.0/24` に一致し、`203.0.114.1` には一致しない
* **#27** 端数ビット：`198.51.100.130` は `198.51.100.128/25` に一致し、`198.51.100.127` は一致しない
* **#28** family 違い：`2001:db8::1` は `0.0.0.0/0` に一致しない。`203.0.113.10` は `::/0` に一致しない
* **#29** `0.0.0.0/0` は任意の IPv4 に一致する（禁止しない）
* **#30** `::ffff:203.0.113.10` は `203.0.113.0/24` に一致する（#3 の帰結）
* **#31** `matchesAnyIpExclusion([], ip)` は常に `false`

### 3.5 Domain：リストの解釈（設計 §4.5）

* **#32** 空行・前後の空白を落とす
* **#33** 正規表記が同じ行は 1 つに畳む（`203.0.113.0/24` と `203.0.113.10/24`）
* **#34** 解釈できない行は `invalid` に**入力のまま**入り、`rules` には入らない
* **#35** `IP_EXCLUSION_RULE_MAX_LENGTH`（64）を超える行は `invalid`
* **#36** `rules` の順は入力順を保つ

### 3.6 Domain：設定の読み出し（設計 §5.1）

* **#37** 値が無ければ `accessLogExcludedIps` は `[]`
* **#38** 配列でない値（文字列・数値・`null`）なら `[]`
* **#39** 配列の中に解釈できない要素があっても、**残りは生きる**（行ごとに落とす）
* **#40** 読み出しでも正規表記へそろえる（`203.0.113.10/24` を保存してあれば `203.0.113.0/24` で返る）
* **#41** `toPublicSystemSettings` の戻り値に `accessLogExcludedIps` が**含まれない**
* **#42** 上限（100 件）を超えて保存されていても、返るのは 100 件まで

### 3.7 送信元 IP の取り出し（設計 §10.1）

* **#43** `clientIpOf` は `x-forwarded-for` の先頭要素を返す
* **#44** `x-forwarded-for` が無ければ `x-real-ip` を返す
* **#45** どちらも無い／空なら `null`
* **#46** `requestInfoOf` の戻り値は従来と変わらない（切り出しで壊れていない）

### 3.8 参照とキャッシュ（設計 §6）

* **#47** `isAccessLogExcluded(null)` は `false`
* **#48** `isAccessLogExcluded('')` は `false`
* **#49** 読めない値（`'not-an-ip'`）は `false`
* **#50** 保存済みリストに一致すれば `true`
* **#51** `primeAccessLogIpExclusions` を呼んだ直後は、DB を読まずにその値で判定する
* **#52** 読み直しが失敗しても**例外を投げず**、直前の値（未読み込みなら空）で `false` を返す（fail-open）
* **#53** キャッシュは `processState` 上にあり、テスト用のリセットで初期化できる

### 3.9 収集（設計 §7）

* **#54** 除外 IP から `collectAccess` を呼ぶと `access_logs` に **1 行も入らない**
* **#55** そのとき戻り値は `{ ok: false }`（受け口は 204 のまま）
* **#56** 除外 IP のときは**サイトの照会もしない**
* **#57** 除外されていない IP は従来どおり記録される
* **#58** `ipAddress` が `null` のときは記録される（#47 の帰結）
* **#59** CIDR で指定した帯の中の IP も記録されない
* **#60** `POST /api/v1/collect` は除外の有無にかかわらず **204** を返す

### 3.10 UseCase（設計 §9）

* **#61** `getAccessLogIpExclusions` は `system.manage` を要求する（権限なしは 403、未認証は 401）
* **#62** `updateAccessLogIpExclusions` も `system.manage` を要求する
* **#63** 保存すると正規化後のリストが返り、`system_settings` にその形で入る
* **#64** 解釈できない行が 1 つでもあれば `ValidationError`。**1 件も保存されない**
* **#65** エラーメッセージには不正な行が**先頭 3 件まで**入る
* **#66** 上限（100 件）を超えると `ValidationError`
* **#67** 空配列を保存できる（全解除）
* **#68** 保存後、同じプロセスの `isAccessLogExcluded` に即座に効く
* **#69** 監査ログの `detail` に **IP そのものが入らない**（設定キーと件数だけ）

### 3.11 API（設計 §8）

* **#70** `PUT /api/v1/settings/access-log-ips` は `system.manage` で 200、権限なしで 403、未認証で 401
* **#71** 応答は `{ data: { rules: [...] } }` で、**正規化後**の値
* **#72** 1 行が 64 文字を超える／101 件以上は 422（Zod）
* **#73** 形式が不正な行は **422**（UseCase の `ValidationError`）
* **#74** このパスに `GET` は無い
* **#75** `GET /api/v1/settings`（`permission: null`）の応答に除外リストが**含まれない**

### 3.12 画面（設計 §10）

* **#76** `system.manage` を持つときだけ区画が描かれる
* **#77** 現在のアクセス元 IP が表示される。取れないときは注意文が出る
* **#78** 「追加」で入力欄の末尾に 1 行足される。既に含まれていれば押せない
* **#79** 保存の成功で `Toast`、失敗で `Alert`。画面の再読み込みはしない
* **#80** 「すでに記録済みのアクセスは消えない」旨の注意文が出ている
