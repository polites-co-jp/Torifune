### 指摘

#### S-1（修正済み）`userRepository.findById` に UUID の形式検査が無かった

`GET /api/v1/users/not-a-uuid` が PostgreSQL の `22P02` で落ち、**500 になっていた。**

`site-repository` には同じ検査があるが、`user-repository` は
`/setup` とログインからしか呼ばれておらず、**外部から任意の文字列が
渡る経路が無かったため必要になっていなかった。**
User API を公開したことで初めて到達可能になった。

受け入れ条件 #17 のテストを先に書いていたため、実装の途中で見つかった。

#### S-2（記録のみ）ロールを編集できないことは、いまは仕様

`user.manage` を持つ利用者は、他人のロールを付け替えられる。
**editor に `user.manage` を与えれば、その人は自分を administrator にできる。**

これは RBAC の性質であって不具合ではないが、
「`user.manage` はロールの付け替えを含む」ことを運用側が理解している必要がある。
既定のロール構成では administrator だけが `user.manage` を持つ。

権限タブを参照のみにしたのは、ここへさらに
「ロール自体へ権限を足す」経路を重ねないため。
