# 057 送信待ちの一括投稿とチェックの当たり判定 検証レポート

送信待ちタブ・投稿タブの選択の当たり判定を「選択の列のセル」と「状態のセル」の全体に広げ（`Table` の `Column.onCellClick`）、

手動投稿は 1 件ずつ投稿画面を開き、とりふねの画面に戻ると「投稿した」「投稿しなかった」が出て、選ぶと次の窓が開く。
**ユーザー裁定（2026-10-27）1〜4** と **U1・U2（どちらも (a)）** は設計の冒頭の表と §11 にある。
