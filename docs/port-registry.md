# ホスト公開ポート台帳（開発環境）

このリポジトリの `compose.yaml` がホストへ公開するポートの記録。

> このファイルは開発時の利便のためのものです。
> Torifune 自体は特定のポート構成を要求しません。すべて環境変数で上書きできます。

## 予約レンジ

| 項目 | 値 |
| --- | --- |
| プロジェクト名 | Torifune |
| ポート開始 | **21700** |
| ポート終了 | **21799** |
| ステータス | active |

## 使用中ポート

| サービス | ホスト公開ポート | コンテナ内部ポート | 上書き用の環境変数 |
| --- | --- | --- | --- |
| postgres | 21700 | 5432 | `TORIFUNE_DB_PORT` |
| postgres-test | 21701 | 5432 | `TORIFUNE_DB_TEST_PORT` |
| （予備） | 21702-21799 | — | — |

**コンテナ内部のリッスンポートは変更しません。** サービス間通信は Compose のサービス名で行います。

アプリケーション本体は開発時にホスト側で `pnpm dev`（既定 3000 番）として動かします。
コンテナで動かす場合は `Dockerfile` を使い、公開ポートは利用者が決めます。

## ポートを変更するとき

1. `compose.yaml` と `.env.example` を更新する
2. この表を更新する
3. 内部ポート（PostgreSQL の 5432 等）は変更しない
