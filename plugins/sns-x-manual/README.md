# X配信・手動投稿（`sns-x-manual`）

Torifune に予約した SNS 投稿を、**X の投稿画面（Web Intent）で手動投稿する** Plugin です（無料版）。

Torifune 本体は「いつ知らせるか・記録・画面」を持っています。
この Plugin が受け持つのは、手動投稿のときに **投稿内容の入った X の投稿画面の URL を組み立てること**だけです。

- **X API の契約も資格情報も要りません。** この Plugin は X へ 1 本も要求を送りません
- **自動投稿はできません。** 予約時刻になると `/social` の「手動投稿待ち」に並び、人が投稿画面を開いて送信します
- 自動で投稿したい場合は、有料版の **「X配信（X API）」（`sns-x-api`）** を使います（下の「無料版と有料版」）

## 無料版と有料版

X への配信 Plugin は 2 つあります。**どちらも provider は `x` で、同時には有効にできません**（片方だけを有効にします）。

|                      | `sns-x-manual`（無料版・この Plugin）                                    | `sns-x-api`（有料版）                                                 |
| -------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| X API の契約         | 要りません                                                               | **要ります**（従量課金のクレジット）                                  |
| 予約時刻に起きること | 「手動投稿待ち」に並びます。**人が投稿画面を開いて送信ボタンを押します** | Torifune が自動で投稿します（`deliveryMode: 'auto'`）。手動も選べます |
| 画像                 | 付けられません（投稿画面で添付します）                                   | 自動配信なら 4 枚まで                                                 |
| 資格情報             | 要りません（`/social` に資格情報の欄は出ません）                         | OAuth 1.0a の 4 つの値（`/social` の「資格情報を設定」で入れます）    |

登録済みの X のアカウントと予約は、どちらの Plugin でもそのまま使えます。**入れ替えても作り直す必要はありません**（下の「入れ替え」）。

## 導入のしかた

1. `plugins/sns-x-manual/` を Torifune の `plugins/` の下に置きます
2. `/plugins` の「検出済み」に **「X配信（手動投稿）」** が現れるので「導入」を押します
3. **再ビルドと再起動が要ります。** Plugin のコードはアプリのビルドに取り込まれるため、
   導入しただけでは動きません（画面の案内に従ってください）
4. `/plugins` で **有効化**します。`sns-x-api` が有効なままだと有効化できません（先に `sns-x-api` を無効化します）
5. `/social` で `provider` が **X** の SNS アカウントを作ります。この Plugin が有効な間は資格情報の欄は出ません（入力は要りません）

この Plugin は画面の設定を持ちません（`/plugins/sns-x-manual/settings` はありません）。

`/plugins` の拡張点の欄には「SNS配信（SNSアカウントの資格情報を受け取ります）」と出ますが、これは `social` を使う Plugin に一律に出る Torifune 本体の表示です。
**この Plugin は資格情報を受け取りません。**

### 以前に入れた資格情報が残っているとき

この Plugin は資格情報を使わないと宣言しているので、有効な間は、SNS アカウントを作る画面にも、
アカウントの行の「資格情報を設定」の画面にも、資格情報の欄は出ません。

以前の版の Torifune では、この Plugin の間もアカウントを作る画面に汎用の資格情報の欄が出ていました。
そこへ値を入れていた場合、その値はこの Plugin の間は読まれません。ところが **有料版（`sns-x-api`）へ入れ替えると「資格情報 設定済み」として扱われ**、
形が合わないため、自動の予約は待たずに**すぐ `failed`** になります（「資格情報の形式が…合いません」）。

- `/social` で X のアカウントの行の「資格情報を設定」を開くと、保存済みの値が残っていれば警告が出ます。不要なら **「資格情報を消す」** で消してください
- 有料版へ入れ替える場合は、下の「入れ替え」の 4 で 4 つの値を入れれば、残っていた値は丸ごと置き換わります

## 手動投稿の流れ

1. `/social` で投稿を作り、**配信方法に「手動」（`deliveryMode: 'manual'`）** を選んで予約します
2. 予約時刻を過ぎると、`/social` の **「手動投稿待ち」** に並びます
3. 「投稿画面を開く」を押すと、**本文の入った X の投稿画面**が別のウィンドウで開きます。
   ブラウザでログインしている X のアカウントで開きます（Torifune からはアカウントを指定できません）
4. 内容を確かめて、X の画面で投稿します
5. Torifune に戻り、**「投稿した」** を押します（投稿をやめたときは「取りやめ」）

X の画面で投稿したかどうかを、Torifune は知ることができません。**「投稿した」を押すまで、手動投稿待ちに残ります。**

### API で登録するときは `manual` を明示してください

**`deliveryMode` を省略すると `auto`（自動）として扱われ、この Plugin では予約の時点で 422 で断られます。**
外部のアプリから `POST /api/v1/social/posts` で登録するときは、`"deliveryMode": "manual"` を必ず指定してください。

- 断るのは、自動の予約を受け付けても**この Plugin では決して配信されない**ためです。
  受け付けてしまうと、何も知らされないまま約24時間後に `failed` になります
- Torifune はこの Plugin に投稿の状態（下書きか予約か）を渡さないため、**`auto` の下書きも同じく断ります**

## 投稿の作りかた（X の制限）

| 決まり            | 値                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------ |
| 本文の長さ        | **重み付きで 280** まで（日本語・絵文字は 1 文字を 2、`https://` で始まる URL は長さによらず 23 と数えます） |
| リンク（`link`）  | **本文の末尾に改行して足します**。足した後の長さで数えます                                                   |
| 画像              | **手動投稿には付けられません**（Torifune が予約の時点で断ります）。投稿画面で添付してください                |
| `providerOptions` | 指定できる項目はありません                                                                                   |

- 上限を超える投稿は、**予約の時点で断ります。** 手動投稿待ちに並んでから初めて開けないと分かることはありません
- 本文に長い URL を含めると、X の数え方では 280 以内でも **投稿画面の URL が長くなりすぎる**ことがあります。
  その場合も予約の時点で断るので、本文中の URL を短くしてください
- `https://` の無いドメイン（`example.com` など）は URL として数えません。X の数え方より少なく数えることがあり、
  その場合は X の投稿画面で送信できなくなります
- 返信・引用・スレッド・投票・長文投稿（X Premium）には対応していません

## 入れ替え

**同時に有効にできるのは片方だけです。入れ替えは「有効な方を無効化してから、もう片方を有効化する」順で行います。**
登録済みの X のアカウントと投稿は provider（`x`）で結びつくので、入れ替えても作り直しません。

### 無料版（この Plugin）から有料版へ

1. `/plugins` で `sns-x-api` を「導入」します（再ビルドと再起動。この間 `sns-x-manual` は有効のまま動きます）
2. `/plugins` で `sns-x-manual` を「無効化」します
3. `/plugins` で `sns-x-api` を「有効化」します
4. `/social` で登録済みの X のアカウントの行の **「資格情報を設定」** を押し、4 つの欄（API Key（Consumer Key）／API Key Secret（Consumer Secret）／
   Access Token／Access Token Secret）に入れて「保存」します。各欄の下に `sns-x-api` の説明が出ます。
   入れるまで、自動の予約は「資格情報 未設定」で待ちます（約24時間まで）
5. 以後の予約は「自動」を選べます。手動の予約はそのまま手動投稿待ちに並びます（同じ投稿画面が開きます）

- **導入を先に済ませる**のは、導入に再ビルドと再起動が伴うためです
- 2〜3 のあいだ（数秒）は、手動投稿待ちの行が「投稿画面を開けません」になりますが、「投稿した」「取りやめ」は押せます
- 4 は API でも行えます（外部のアプリから入れる場合や、無料版の間に先に入れておく場合）。要求の形です（`social.write` の権限で送ります。`{id}` は X のアカウントの ID）：

  ```http
  PATCH /api/v1/social/accounts/{id}
  Content-Type: application/json

  {
    "credentials": {
      "apiKey": "…",
      "apiKeySecret": "…",
      "accessToken": "…",
      "accessTokenSecret": "…"
    }
  }
  ```

- 本文や API Token（`tfp_` で始まる値）をコマンドラインに直書きしないでください（シェルの履歴やプロセスの一覧に残ります）。ファイルか標準入力で渡してください
- 4 の値は、無料版の間に上の要求（API）で先に入れておけます（この Plugin の間は読まれません）。
  画面からは先に入れられません（この Plugin の間は「資格情報を設定」に資格情報の欄が出ないため）
- 4 で入れた値は、保存済みの資格情報を**丸ごと置き換えます**。一部の項目だけを入れ直すことはできないので、4 つとも入れてください
- 以前の版の Torifune で汎用の資格情報の欄に何かを入れていた場合は、**1 の前に**「資格情報を設定」の「資格情報を消す」で消すか、4 で 4 つの値に置き換えてください（上の「以前に入れた資格情報が残っているとき」）
- **順序を間違えた場合**（`sns-x-manual` を有効にしたまま `sns-x-api` を有効化した場合）、`sns-x-api` は有効化に失敗して `disabled` になり、
  `/plugins` に理由（provider `x` は別の Plugin が既に登録している）が出ます。**`sns-x-manual` は動き続け、何も失われません。** 2 からやり直してください

### 有料版からこの Plugin へ

1. `/plugins` で `sns-x-api` を「無効化」し、`sns-x-manual` を「有効化」します
2. 残っている「自動」の予約を「手動」に直します（`deliveryMode` を `manual` に。画像を付けた予約は画像を外します）

- 直さずに残した自動の予約は配信されずに待たされ、**約24時間で `failed` になります。** `/social` の表示が知らせます
- `sns-x-api` に入れていた 4 つの値は**残りますが、読まれません。** 消したい場合は、`/social` で X のアカウントの行の「資格情報を設定」を開き、
  **「資格情報を消す」** を押します（残っている間はそこに警告が出ます）。API では `PATCH /api/v1/social/accounts/{id}` に `{ "credentials": {} }` を送ります

## この Plugin が持つもの・持たないもの

- **状態を 1 つも持ちません。** 設定もなく、投稿の状態も自分では保存しません
- 資格情報を受け取らず、**X へも他のどこへも要求を送りません**
- Torifune の Permission を 1 つも追加しません。データベースにも直接触りません
- 投稿画面の URL を組み立てる `x-text.ts` は、`sns-x-api` と**同じ内容のファイル**です。2 つの Plugin で手動投稿の結果が食い違わないよう、一致をテストで確かめています
- この Plugin は実際の X ではまだ動かしていません。導入したら、まずテスト用の投稿で投稿画面が開くことを確かめてください

同じ provider の Plugin を複数作るときは、共有したいファイルを各 Plugin に複製し、一致をテストで固定してください（Plugin は隣の Plugin のファイルを import できません）。
