## 見出し

ファイルの先頭の `#` の題名は、画面では描きません（画面の大きな題名は Manifest の `title` が持ちます）。
本文の見出しは `##` から書きます。見出しには自動で `help-` から始まる ID が付き、目次のリンクから飛べます。

Torifune ではこう描かれる：この「見出し」のような中見出しになります。

## 段落と強調

空の行で段落を分けます。**太字**、_斜体_、~~打ち消し線~~、`インラインのコード` が使えます。

> 引用は左に線の付いた囲みになります。

Torifune ではこう描かれる：この段落と上の引用のとおりです。

## リスト

- 箇条書き
  - 入れ子の箇条書き
- もう 1 つの項目

1. 番号付きの手順
2. 次の手順

- [x] 済んだこと
- [ ] まだのこと

Torifune ではこう描かれる：上のとおり。番号付きのリストは手順を書くのに使います。

## 表

長い識別子が並ぶ表は、狭い画面では表の枠の中だけが横に動きます（ページ全体は動きません）。

| 欄のキー                             | 権限の名前の例                     | 値の形の例             | 備考の例                                |
| ------------------------------------ | ---------------------------------- | ---------------------- | --------------------------------------- |
| `example_plugin_credential_handle`   | `example_social_content_publish`   | `xxxx-xxxx-xxxx-xxxx`  | `do_not_paste_this_value_anywhere_else` |
| `example_plugin_credential_password` | `example_social_account_read_only` | `2026-11-23T00:00:00Z` | `renew_before_the_expiration_date`      |

Torifune ではこう描かれる：罫線の付いた表になります。

## コード

囲みのコードは、色付けをせずにそのまま描きます。長い行は折り返さず、枠の中で横に動きます。

```text
{"help":[{"id":"usage","title":"サンプルSNS の資格情報の用意のしかた","path":"help/usage.md"},{"id":"markdown","title":"手順書で使える書き方","path":"help/markdown.md"}]}
```

囲みの中の `<b>` のような字は、そのままの文字として見えます。

```html
<b>太字にはなりません</b>
```

Torifune ではこう描かれる：上の 2 つの囲みのとおりです。

## リンク

- 外部のサイトへのリンク：[CommonMark の書き方の説明](https://commonmark.org/help/)。新しいタブで開き、文言の後に「↗」が付きます
- URL をそのまま書いても外部へのリンクになります：https://github.github.com/gfm/
- 同じ Plugin の手順書へのリンクは、ファイルからの相対パスで書きます：[サンプルSNS の資格情報の用意のしかた](./usage.md)。同じタブで開きます
- 本文の見出しへのリンクは `#` から書きます：[表の見本へ](#表)

Torifune ではこう描かれる：上のとおり。宣言していないファイル（README など）への相対リンクは、リンクにならず文字だけが残ります。

## 描かれないもの

手順書は HTML を通さずに描きます。次のものは、書いても要素になりません。

### 画像

![手順の画面](https://example.com/a.png)

Torifune ではこう描かれる：画像は表示せず、上のように「［画像：説明］」の文字になります。手順書にはスクリーンショットを載せません。

### 生の HTML

<script>alert(1)</script>

Torifune ではこう描かれる：上の行は実行されず、書いたとおりの文字として見えます。

### 危ないリンク

[押す](<javascript:alert(1)>)

Torifune ではこう描かれる：`javascript:` で始まるリンクはリンクにならず、文言だけが残ります。
