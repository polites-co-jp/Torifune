## この手順書でそろうもの

| Torifune の欄の名前   | 入れるもの                                            |
| --------------------- | ----------------------------------------------------- |
| サンプルSNSのハンドル | サンプルSNS での利用者名（例：`example`）             |
| アプリパスワード      | サンプルSNS が発行する `xxxx-xxxx-xxxx-xxxx` の形の値 |

## 全体の流れ

1. サンプルSNS でアプリパスワードを発行する
2. Torifune の `/social` で 2 つの欄に入れる

## 手順 1：サンプルSNS でアプリパスワードを発行する

本物の手順書では、ここに「開く画面」「押すもの」「確かめること」を 1 つの操作ごとに書きます。

- **開く画面**：サンプルSNS の設定の画面
- **押すもの**：「アプリパスワードを追加」
- **確かめること**：`xxxx-xxxx-xxxx-xxxx` の形の値が表示されること

## 手順 2：Torifune に入れる

- 新しくアカウントを作るときは、`/social` の「+ アカウントを追加」で開く「SNSアカウントを追加」の画面で、「サービス」に「サンプルSNS」を選びます
- すでにあるアカウントに入れるときは、アカウントの行の「資格情報を設定」を押します

どちらの画面でも、「サンプルSNSのハンドル」と「アプリパスワード」の 2 つの欄に、手順 1 の値を入れます。

## 安全のために

- 値は Torifune 以外に貼らないでください
- 保存した値は暗号化され、画面に再表示されません。入れ直すときは 2 つの欄を両方とも入れ直します
