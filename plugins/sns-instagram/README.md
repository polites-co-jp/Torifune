# Instagram配信（`sns-instagram`）

Torifune に予約した SNS 投稿を、**Instagram（Graph API の Content Publishing）へ配信する** Plugin です。

Torifune 本体は「いつ送るか・再試行・記録・画面」を持っています。
この Plugin が受け持つのは **1 件を Instagram へ公開すること**と、
**必要ならアクセストークンを延長して Torifune へ返すこと**だけです。

**画像だけを配信します。動画（リール）とストーリーズには対応していません。**
**手動投稿（`deliveryMode: 'manual'`）にも対応していません**（Instagram には投稿内容を反映した投稿画面の URL がないため）。
手動投稿で予約しようとすると、Torifune が予約の時点で断ります。

## 導入のしかた

1. `plugins/sns-instagram/` を Torifune の `plugins/` の下に置きます
2. `/plugins` の「検出済み」に **「Instagram配信」** が現れるので「導入」を押します
3. **再ビルドと再起動が要ります。** Plugin のコードはアプリのビルドに取り込まれるため、
   導入しただけでは動きません（画面の案内に従ってください）
4. `/plugins` で **有効化**します
5. `/social` で `provider` が **Instagram** の SNS アカウントを作り、資格情報（3 項目）を入れます

この Plugin は画面の設定を持ちません（`/plugins/sns-instagram/settings` はありません）。

## 用意するもの

### Instagram のプロアカウント

**Instagram のプロアカウント（ビジネスまたはクリエイター）が要ります。**
個人アカウントには API から投稿できません。個人アカウントのままだと、配信のときに「権限が足りません」という理由で失敗します。

### 長期アクセストークンとユーザー ID

Meta の開発者向け画面で、次の手順で用意します（画面の名前は Meta 側の変更で変わることがあります）。

1. Meta for Developers で App を作り、**Instagram API（Instagram ログイン）** を追加します
2. 投稿に使う Instagram のプロアカウントでログインし、次の 2 つの権限を許可します
   - `instagram_business_basic`
   - `instagram_business_content_publish`
3. 発行された短期のアクセストークンを **長期アクセストークン** に交換します
4. ユーザー ID を確かめます。長期アクセストークンで自分のアカウントの情報（`me` の `user_id`）を問い合わせると分かります。
   **数字だけの ID です。`@` で始まるユーザーネームではありません**

### Torifune に入れる 3 項目

| 項目                  | 入れるもの                                                                    |
| --------------------- | ----------------------------------------------------------------------------- |
| Instagram ユーザー ID | 数字だけの ID（例：`17841400000000000`）。ユーザーネームではありません        |
| 長期アクセストークン  | 上で発行した長期アクセストークン                                              |
| トークンの有効期限    | 例：`2026-11-22T00:00:00Z`。**分からなければ `unknown` と入れてかまいません** |

Torifune に保存した資格情報は暗号化され、**保存後は画面に再表示されません**（入れ直しは `/social` のアカウントの行の「資格情報を設定」からできます）。

## トークンは60日で失効します

長期アクセストークンの有効期限は **60日**です。

- Torifune が延長するのは、**配信が成功したときだけ**です。
  配信が成功した時点で**残りが 30 日を切っていれば**（または期限が `unknown` なら）トークンを延長し、
  新しいトークンと期限を Torifune が保存し直します
- **30 日以上配信しない期間があると、トークンはそのまま失効しえます。**
  失効すると、次の配信は「アクセストークンが無効か期限切れです」という理由で失敗します。
  その場合は長期アクセストークンを発行し直し、`/social` のアカウントの行の「資格情報を設定」から資格情報を登録し直してください
- 期限に `unknown` を入れた場合は、**次に配信が成功したときに延長を試み**、正しい期限に書き換えます
- 延長に失敗しても、**投稿そのものは成功として扱います**（理由はサーバのログにだけ残ります）

## 資格情報を入れるまでの猶予は約24時間です

Plugin を有効にしていない、あるいは資格情報を入れていない状態でも、投稿の予約そのものは受け付けます。
ただしその投稿は配信されずに待たされ、**予約時刻から約24時間で `failed` になります。**

`failed` は終端の状態です。**そこから配信し直すことはできず、新しい投稿として登録し直す**ことになります。
予約を入れたら、24時間以内に有効化と資格情報の登録を済ませてください。

## 投稿の作りかた（Instagram の制限）

| 決まり              | 値                                                                                             |
| ------------------- | ---------------------------------------------------------------------------------------------- |
| 画像                | **1〜10 枚**。**画像なしでは予約できません**。2 枚以上ならカルーセル（複数枚の投稿）になります |
| キャプション        | **2200文字**まで                                                                               |
| ハッシュタグ        | **30個**まで（全角の `＃` も数えます）                                                         |
| メンション          | **20件**まで                                                                                   |
| リンク（`link`）    | **指定できません**                                                                             |
| 画像の説明（`alt`） | **Instagram へは送られません**（指定しても断りはしません）                                     |

- 上限を超える投稿は、**予約の時点で断ります。** 配信の直前になって初めて弾かれることはありません
- **`link` は指定できません。** Instagram はキャプション内の URL をリンクにしないためです。
  URL を見せたい場合は本文に書いてください（リンクにはなりません）
- `providerOptions` に指定できる項目はありません
- 投稿の削除・編集・コメント・位置情報・タグ付けには対応していません

### 画像は公開された JPEG の URL で渡します

**Torifune は画像ファイルを預かりません。** 投稿に添える画像は、
**インターネットから誰でも取得できる JPEG 画像の `https://` の URL** として渡してください。

- 画像を取りに行くのは **Instagram のサーバ**です。Torifune のサーバは画像の URL へアクセスしません
- **画像の URL は Meta へ送られます**（URL に含まれるクエリ文字列も含めて）。署名付き URL を使う場合は、そのことを踏まえてください
- 社内ネットワークの中など、インターネットから取得できない URL では配信に失敗します

### 動画は扱いません

**動画の URL を渡しても、予約の時点では断れません。** Torifune もこの Plugin も、URL の先が画像か動画かを知る手段を持たないためです。
**動画の URL を指定した投稿は、配信のときに Instagram が画像として処理できずに `failed` になります**（再試行はしません）。
動画を投稿したい場合は、Instagram のアプリから投稿してください。

なお、画像なしで予約しようとしたときの Torifune の案内文は「画像または動画が必要です」と表示されますが、
**この Plugin が配信できるのは画像だけです。**

## 24 時間あたりの公開数の上限

Instagram には **24 時間あたりに公開できる投稿数の上限**があります（値は Instagram 側で変わるため、ここには書きません）。
上限に達すると、その投稿は「公開数の上限に達しました」という理由で `failed` になります。時間をおいて新しい投稿として登録し直してください。

## うまくいかないとき

配信に失敗した投稿は `/social` の履歴に**理由**が残ります。よくあるものは次のとおりです。

| 履歴に出ること                                     | 見るところ                                                                                                         |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| アクセストークンが無効か期限切れです               | 長期アクセストークンを発行し直し、`/social` のアカウントの行の「資格情報を設定」から資格情報を登録し直してください |
| 権限が足りません                                   | プロアカウントであること、`instagram_business_content_publish` の権限があることを確かめてください                  |
| 画像を処理できませんでした・受け付けませんでした   | 画像の URL が公開された JPEG 画像を指しているか確かめてください（動画の URL ではありませんか）                     |
| 公開数の上限に達しました                           | 時間をおいて新しい投稿として登録し直してください                                                                   |
| 接続できませんでした・一時的に応答できませんでした | しばらく待つと Torifune が自動で送り直します                                                                       |
| 公開の要求が届いたかを確認できませんでした         | **二重投稿を避けるため再試行しません。** Instagram 側で投稿されたかを確かめてから、必要なら予約し直してください    |

失敗の理由に**資格情報そのものは書かれません。** Instagram が返した自由な文言も載せません。

## Graph API の版

この Plugin は Graph API の **`v26.0`** を使います（`graph.ts` の `GRAPH_API_VERSION`）。

- **Instagram ログイン版の Graph API が `v26.0` を受け付けることは、実機ではまだ確かめていません。**
  Meta の Graph API の変更履歴で最新の版として公開されている値を使っています
- Graph API の版はおよそ 2 年で廃止されます。**版が廃止されたら、この Plugin の更新が要ります**
  （Torifune 本体の更新は要りません）
- この Plugin は実際の Instagram ではまだ動かしていません。導入したら、まずテスト用の投稿で疎通を確かめてください

## この Plugin が持つもの・持たないもの

- **状態を 1 つも持ちません。** 設定もなく、投稿の状態も資格情報も自分では保存しません（延長したトークンは Torifune 本体が保存します）
- アクセストークンの送り先は Instagram の Graph API に固定されています。設定で変えることはできません
- **延長の要求（`refresh_access_token`）は、Graph API の仕様で URL のクエリにアクセストークンが入ります。**
  この Plugin はその URL をログにも失敗の理由にも出しませんが、Torifune の `fetch` に計測（OpenTelemetry・Sentry など）を足すときは、**要求の URL のクエリを伏せる設定にしてください**
- Torifune の Permission を 1 つも追加しません。データベースにも直接触りません
