# Bluesky配信（`sns-bluesky`）

Torifune に予約した SNS 投稿を、**Bluesky（AT Protocol）へ配信する** Plugin です。

Torifune 本体は「いつ送るか・再試行・記録・画面」を持っています。
この Plugin が受け持つのは **1 件を Bluesky へ送ること**と、
手動投稿のときに **Bluesky の投稿画面（Web Intent）の URL を組み立てること**だけです。

## 導入のしかた

1. `plugins/sns-bluesky/` を Torifune の `plugins/` の下に置きます
2. `/plugins` の「検出済み」に **「Bluesky配信」** が現れるので「導入」を押します
3. **再ビルドと再起動が要ります。** Plugin のコードはアプリのビルドに取り込まれるため、
   導入しただけでは動きません（画面の案内に従ってください）
4. `/plugins` で **有効化**します
5. `/social` で `provider` が **Bluesky** の SNS アカウントを作り、資格情報を入れます

## App Password を用意する

**Bluesky にログインするパスワードではありません。** ログイン用のパスワードをここへ入れないでください。

1. Bluesky の **設定 → プライバシーとセキュリティ → アプリパスワード** を開きます
2. 新しいアプリパスワードを発行します。`xxxx-xxxx-xxxx-xxxx` の形の文字列が一度だけ表示されます
3. Torifune の `/social` でアカウントを編集し、次の 2 つを入れます

   | 項目                             | 入れるもの                                                        |
   | -------------------------------- | ----------------------------------------------------------------- |
   | ハンドルまたはメールアドレス     | `example.bsky.social` のようなハンドル（先頭の `@` は書きません） |
   | App Password（アプリパスワード） | 2 で発行した `xxxx-xxxx-xxxx-xxxx`                                |

App Password は **いつでも個別に取り消せます。** 取り消すと、この Plugin からの配信だけが止まります。
Torifune に保存した App Password は暗号化され、**保存後は画面に再表示されません**（入れ直しはできます）。

### 資格情報を入れるまでの猶予は約24時間です

Plugin を有効にしていない、あるいは資格情報を入れていない状態でも、投稿の予約そのものは受け付けます。
ただしその投稿は配信されずに待たされ、**予約時刻から約24時間で `failed` になります。**

`failed` は終端の状態です。**そこから配信し直すことはできず、新しい投稿として登録し直す**ことになります。
予約を入れたら、24時間以内に有効化と資格情報の登録を済ませてください。

## 投稿の作りかた（Bluesky の制限）

| 決まり             | 値                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------ |
| 本文の長さ         | **300文字**まで（絵文字や結合文字は 1 文字として数えます。UTF-8 で 3000 バイトまで） |
| 画像               | **4枚**まで                                                                          |
| 画像とリンクカード | **画像とリンクカードは同時に付けられません**（どちらか一方だけです）                 |
| 言語               | `providerOptions` に `{"langs": ["ja"]}` のように指定できます（3 件まで）            |

- 上限を超える投稿は、**予約の時点で断ります。** 配信の直前になって初めて弾かれることはありません
- 本文に `https://…` を含めると、**Bluesky 上でリンクとして表示されます**
- リンクカード（`link`）を付けると、見出しにはリンク先のホスト名が入ります。
  リンク先の内容は取りに行かないため、見た目は素っ気なくなりますが、リンクは開けます
- 返信・引用・スレッド・動画には対応していません

### 画像は公開された URL で渡します

**Torifune は画像ファイルを預かりません。** 投稿に添える画像は、
**誰でも取得できる `https://` の URL** として渡してください。

- 1 枚あたり **1MB** まで
- `Content-Type` が画像であるものだけを受け付けます
- **転送（リダイレクト）は追いません。** 転送される URL を指定した場合は、転送先の URL を直接渡してください

画像の説明（alt）は 1000 文字までです。

## PDS の URL（通常は変更しません）

`/plugins/sns-bluesky/settings` で、投稿先の **PDS（Personal Data Server）** を変えられます。
空欄なら `https://bsky.social` を使います。**自分で PDS を運用している場合だけ**、その URL を入れてください。

- **ここで指定したサーバへ、登録された App Password がそのまま送られます**
- `https` の URL だけを受け付けます。ホストまでを入れてください（例：`https://bsky.social`）
- **1 つの Torifune は 1 つの PDS を見ます。** アカウントごとに別の PDS を指すことはできません
- 設定を変えられるのは、Plugin の導入を許された利用者（`plugin.manage`）だけです

## うまくいかないとき

配信に失敗した投稿は `/social` の履歴に**理由**が残ります。よくあるものは次のとおりです。

| 履歴に出ること             | 見るところ                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| ログインに失敗しました     | App Password が違う・取り消されている。ログイン用のパスワードを入れていないか確かめてください |
| アカウントが利用できません | Bluesky 側でアカウントが停止・削除されていないか確かめてください                              |
| 接続できませんでした       | PDS の URL と、Torifune から外部へ出られるかを確かめてください。しばらく待つと再試行します    |
| 画像を取得できませんでした | 画像の URL が公開されているか、1MB 以内か、転送されていないかを確かめてください               |
| ログインが集中しています   | Bluesky 側の制限です。Torifune が待ってから自動で送り直します                                 |

失敗の理由に**資格情報そのものは書かれません。** 送り先のサーバが返した自由な文言も載せません。

## この Plugin が持つもの・持たないもの

- 持つのは **PDS の URL の設定 1 件だけ**です。投稿の状態も資格情報も自分では保存しません
- Torifune の Permission を 1 つも追加しません。データベースにも直接触りません
- 投稿の削除・編集はできません（Bluesky へ送ったあとは取り消せないためです）
